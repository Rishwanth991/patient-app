# Patient Management System

## Overview
A web-based Patient Management System developed using Java Servlets, JDBC, Oracle Database, and Apache Tomcat. It allows users to manage patient records efficiently.

## Features
- Add Patient
- View Patient Details
- Update Patient Information
- Delete Patient Records
- Oracle Database Integration

## Tech Stack
- Java
- Servlets
- JDBC
- Oracle Database
- Apache Tomcat
- HTML
- CSS
